Документы Conation — это Markdown-native рабочие файлы, связанные с остальным пространством через @упоминания. Их можно хранить в [папках](/product/folders), открывать в нескольких панелях, искать через [поиск](/product/search) и использовать как контекст для агентов.

<Note>
  Старое видео прежнего интерфейса убрано из активной страницы. Новую
  демонстрацию редактора нужно записать в Conation на синтетических данных и с
  русским интерфейсом.
</Note>

## Создание

Создать новый Markdown-документ: <kbd>c</kbd> + <kbd>d</kbd>.

Документ можно создать из общего меню создания, из папки, из канала или по запросу к агенту.

## Совместное редактирование

Редактор синхронизирует изменения почти мгновенно. Несколько участников могут одновременно править один документ, видеть присутствие друг друга и продолжать работу даже при кратких сетевых сбоях.

## Связи с рабочим пространством

Документ можно упомянуть в канале, задаче, письме или чате с агентом. Упоминания создают traceable-связи: позже можно открыть References и увидеть, где документ обсуждался или использовался.

Права доступа не выдаются автоматически при упоминании в документе. Если вы ссылаетесь на закрытый файл, отдельно проверьте sharing settings.

## Возможности редактора

Редактор поддерживает абзацы, заголовки, маркированные и нумерованные списки, checklist, цитаты, code blocks, таблицы, изображения, видео, PDF-вложения, @упоминания и встроенные блоки.

## Документы и агенты

Агент может читать документ, отвечать по нему, готовить summary, находить противоречия и создавать продолжение работы.

```text
Прочитай этот документ и составь список решений, рисков и задач,
которые нужно завести до конца недели.
```
