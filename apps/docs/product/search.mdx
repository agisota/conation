Поиск — самый быстрый способ найти рабочий объект в Conation. Он ищет не только по названиям: индексируются тексты документов, цепочки писем, сообщения каналов, расшифровки звонков и содержимое файлов.

<Note>
  Старые скриншоты прежнего интерфейса убраны из активной страницы. Для
  публичной документации нужны новые изображения Conation на тестовых данных.
</Note>

## Быстрый запуск

Откройте поиск клавишей <kbd>/</kbd> или через меню <kbd>cmd</kbd> + <kbd>k</kbd>.

Если нужно найти точную фразу, заключите ее в кавычки. Без кавычек поиск сопоставляет слова независимо и поднимает наиболее релевантные результаты.

## Фильтры

Кнопка фильтров в правом верхнем углу сужает выдачу по типу объекта: документы, письма, каналы, задачи, звонки, агенты, файлы и другие блоки.

Чтобы быстро посмотреть результат, используйте <kbd>l</kbd> для предпросмотра. Если объект нужно открыть рядом с текущей работой, откройте его в новой панели.

## Поиск по людям и тегам

Запрос можно уточнить @упоминанием человека. Это полезно, когда вы помните участника обсуждения, но не точное название документа или задачи.

Для поиска по тегам откройте фильтр и выберите chip **Tags**. Если выбрано несколько тегов, Conation позволяет переключить режим совпадения: найти объекты с любым из тегов или только объекты, где присутствуют все выбранные теги.

## Поиск через агента

Если нужен не список результатов, а готовый ответ, задайте вопрос [агенту](/product/agents). Агент использует единую память, поэтому может прочитать связанные документы, письма, задачи и обсуждения, а затем вернуть краткое резюме со ссылками на источники.
