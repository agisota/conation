Задачи Conation достаточно легкие для личной работы и при этом подходят для команды. Задачу можно упомянуть в документе, канале, письме или чате с агентом, чтобы сохранить связь с исходным контекстом.

<Note>
  Старые иллюстрации прежнего интерфейса убраны из активной страницы. Новые
  изображения задач должны быть сняты в Conation на синтетических данных.
</Note>

## Создание

Создать новую задачу: <kbd>c</kbd> + <kbd>t</kbd>.

Задачу можно создать из меню создания, из канала, из письма или по запросу к агенту.

## Основные свойства

У задач есть системные свойства:

- **Status** — текущее состояние работы.
- **Priority** — важность задачи.
- **Assignees** — ответственные исполнители.

Если команде нужны дополнительные поля, добавьте их через [свойства](/concepts/properties).

## Связанный контекст

Задачи работают лучше, когда рядом есть источник решения: канал, письмо, документ, звонок или файл. Упомяните нужный объект через `@`, чтобы сохранить traceable-связь.

Из канала или письма можно быстро создать задачу по фрагменту обсуждения. Это помогает не терять договоренности после переписки.

## Обзор задач

Команда может смотреть задачи вручную в task-модуле или просить агента подготовить обновление.

```text
Покажи задачи проекта Atlas, которые зависли больше недели.
Для каждой найди последнее обсуждение и предложи следующий шаг.
```
