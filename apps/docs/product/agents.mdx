Агенты Conation живут рядом с рабочими данными. Они отвечают на вопросы, готовят черновики, создают задачи, суммируют обсуждения и запускают повторяемые сценарии с учетом [единой памяти](/product/unified-memory).

<Note>
  Старые скриншоты прежнего интерфейса убраны из активной страницы. Для
  публичной документации нужны новые Conation-снимки на тестовых данных.
</Note>

## Вкладка агентов

Модуль агентов показывает историю чатов. Каждый чат автоматически получает название по первому сообщению, и к нему можно вернуться позже.

Открыть агентов: <kbd>g</kbd> + <kbd>a</kbd>.

Перемещаться по чатам: <kbd>j</kbd> и <kbd>k</kbd>.

Создать новый чат с агентом: <kbd>c</kbd> + <kbd>a</kbd>.

## Контекст

Агент может отвечать по документам, письмам, задачам, каналам, звонкам и файлам, если у пользователя есть доступ к этим объектам. Если нужно зафиксировать точный источник, добавьте @упоминание прямо в запрос.

```text
Разбери @[клиентскую цепочку писем] и @[договор].
Составь список открытых вопросов перед следующим звонком.
```

## Автоматизации

Автоматизация — это агентский сценарий, который запускается по расписанию или событию. Например, можно каждый день получать сводку входящих Signal или каждую пятницу — итог по проектам команды.

```text
Каждый будний день в 9:00: проверь мои задачи с просроченным сроком,
найди связанные обсуждения и подготовь короткий план на сегодня.
```

## Отправка действий

Агенты могут создавать документы, задачи, комментарии и черновики писем. Для безопасной работы просите сначала подготовить черновик или план, а отправку и внешние действия подтверждайте вручную.
