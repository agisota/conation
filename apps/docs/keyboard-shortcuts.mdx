## Глобальные

<kbd>c</kbd> Открыть меню создания.

<kbd>cmd</kbd> + <kbd>k</kbd> Открыть command menu.

<kbd>cmd</kbd> + <kbd>{"\\"}</kbd> Создать новую панель.

<kbd>cmd</kbd> + <kbd>;</kbd> Открыть или закрыть настройки.

<kbd>cmd</kbd> + <kbd>.</kbd> Показать или скрыть sidebar и боковые панели.

<kbd>cmd</kbd> + <kbd>z</kbd> Отменить действие.

<kbd>shift</kbd> + <kbd>cmd</kbd> + <kbd>z</kbd> Повторить действие.

<kbd>j</kbd> / <kbd>k</kbd> Навигация по спискам в стиле vim.

<kbd>enter</kbd> Открыть в текущей панели.

<kbd>shift</kbd> + <kbd>enter</kbd> Открыть в новой панели.

<kbd>escape</kbd> Закрыть launcher или сбросить текущее действие.

## Меню создания

<kbd>c</kbd> + <kbd>d</kbd> Создать документ.

<kbd>c</kbd> + <kbd>t</kbd> Создать задачу.

<kbd>c</kbd> + <kbd>e</kbd> Создать письмо.

<kbd>c</kbd> + <kbd>m</kbd> Создать сообщение.

<kbd>c</kbd> + <kbd>g</kbd> Создать канал.

<kbd>c</kbd> + <kbd>a</kbd> Создать AI-чат.

<kbd>c</kbd> + <kbd>n</kbd> Создать canvas.

<kbd>c</kbd> + <kbd>f</kbd> Создать папку.

<kbd>c</kbd> + <kbd>o</kbd> Создать code-файл.

<kbd>c</kbd> + <kbd>s</kbd> Создать snippet.

## Навигация по спискам

<kbd>j</kbd> / <kbd>↓</kbd> Перейти вниз.

<kbd>k</kbd> / <kbd>↑</kbd> Перейти вверх.

<kbd>h</kbd> / <kbd>←</kbd> Свернуть элемент.

<kbd>l</kbd> / <kbd>→</kbd> Развернуть элемент.

<kbd>shift</kbd> + <kbd>j</kbd> / <kbd>shift</kbd> + <kbd>↓</kbd> Расширить
выделение вниз.

<kbd>shift</kbd> + <kbd>k</kbd> / <kbd>shift</kbd> + <kbd>↑</kbd> Расширить
выделение вверх.

<kbd>g</kbd>
<kbd>g</kbd> Перейти к началу списка.

<kbd>shift</kbd> + <kbd>g</kbd> Перейти к концу списка.

<kbd>x</kbd> Выделить или снять выделение с элемента.

<kbd>cmd</kbd> + <kbd>a</kbd> Выделить всё.

<kbd>tab</kbd> Следующая вкладка.

<kbd>shift</kbd> + <kbd>tab</kbd> Предыдущая вкладка.

<kbd>1</kbd>–<kbd>9</kbd> Перейти к вкладке по номеру.

<kbd>cmd</kbd> + <kbd>f</kbd> Поиск внутри списка.

<kbd>escape</kbd> Очистить выделение.

## Действия с объектами

<kbd>e</kbd> Пометить как завершенное.

<kbd>delete</kbd> / <kbd>backspace</kbd> Удалить выбранные элементы.

<kbd>r</kbd> Переименовать.

<kbd>cmd</kbd> + <kbd>d</kbd> Дублировать.

<kbd>m</kbd> Переместить в папку.

<kbd>shift</kbd> + <kbd>cmd</kbd> + <kbd>c</kbd> Скопировать ссылку.

## Задачи

<kbd>shift</kbd> + <kbd>cmd</kbd> + <kbd>b</kbd> Скопировать имя branch.

<kbd>shift</kbd> + <kbd>cmd</kbd> + <kbd>o</kbd> Открыть редактор свойств.

<kbd>shift</kbd> + <kbd>cmd</kbd> + <kbd>p</kbd> Установить приоритет.

<kbd>shift</kbd> + <kbd>cmd</kbd> + <kbd>a</kbd> Назначить исполнителя.

<kbd>shift</kbd> + <kbd>cmd</kbd> + <kbd>s</kbd> Установить статус.

## Каналы и сообщения

<kbd>↑</kbd> / <kbd>↓</kbd> Предыдущее или следующее сообщение.

<kbd>shift</kbd> + <kbd>g</kbd> Перейти к последнему сообщению.

<kbd>enter</kbd> Ответить на сообщение.

<kbd>e</kbd> Редактировать сообщение.

<kbd>backspace</kbd> Удалить сообщение.

<kbd>cmd</kbd> + <kbd>f</kbd> Найти в канале.

<kbd>escape</kbd> Очистить выделение.

## Markdown-редактор

<kbd>cmd</kbd> + <kbd>b</kbd> Жирный текст.

<kbd>cmd</kbd> + <kbd>i</kbd> Курсив.

<kbd>cmd</kbd> + <kbd>u</kbd> Подчеркнутый текст.

<kbd>shift</kbd> + <kbd>cmd</kbd> + <kbd>x</kbd> Зачеркнутый текст.

<kbd>shift</kbd> + <kbd>cmd</kbd> + <kbd>h</kbd> Подсветка.

<kbd>cmd</kbd> + <kbd>e</kbd> Inline code.

<kbd>;</kbd> Вставить snippet.

## Canvas

<kbd>v</kbd> Инструмент выбора.

<kbd>h</kbd> Рука для перемещения по canvas.

<kbd>r</kbd> Фигура.

<kbd>x</kbd> Соединитель.

<kbd>p</kbd> Pencil.

<kbd>t</kbd> Текст.

<kbd>cmd</kbd> + <kbd>=</kbd> / <kbd>cmd</kbd> + <kbd>-</kbd> Приблизить или
отдалить.

<kbd>cmd</kbd> + <kbd>g</kbd> Сгруппировать выделение.

<kbd>shift</kbd> + <kbd>cmd</kbd> + <kbd>g</kbd> Разгруппировать.

<kbd>]</kbd> / <kbd>[</kbd> Переместить вперед или назад по слоям.

<kbd>↑</kbd> <kbd>↓</kbd> <kbd>←</kbd> <kbd>→</kbd> Сдвинуть выделение.
Удерживайте <kbd>shift</kbd> для большего шага.

## Панели

<kbd>cmd</kbd> + <kbd>escape</kbd> Закрыть панель или перейти домой.

<kbd>shift</kbd> + <kbd>escape</kbd> Развернуть панель.

<kbd>shift</kbd> + <kbd>h</kbd> Перевести фокус на панель слева.

<kbd>shift</kbd> + <kbd>l</kbd> Перевести фокус на панель справа.
