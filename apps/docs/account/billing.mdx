В Conation нет продуктовых тарифов, платных мест в команде и ограничений
функций по подписке. Пользовательские возможности приложения доступны
бесплатно и для личной работы, и для команд.

## Что всё равно может стоить денег

Бесплатность продукта не оплачивает внешнюю инфраструктуру. Владелец
развёртывания самостоятельно несёт расходы на серверы, хранение, домен,
резервные копии, доставку почты и сторонние API. В частности, AI-модели,
Google/Gmail, GitHub и другие провайдеры могут устанавливать свои тарифы и
лимиты.

## Платёжный код в репозитории

В унаследованном коде могут оставаться интеграции Stripe и прежние структуры
подписки как технические контракты. Они не определяют модель доступа Conation
и не должны включать платный gate в standalone-развёртывании.

## Лицензия

Исходный код распространяется по AGPLv3. При предоставлении изменённой версии
по сети учитывайте обязанность предоставить соответствующий исходный код её
пользователям. Сторонние компоненты и API сохраняют собственные лицензии и
условия. Технические границы самостоятельного запуска перечислены в
[FAQ](/faq).
