Conation можно использовать в браузере или собрать в оболочке Tauri. Пока
публичный production-контур не подтверждён, воспроизводимый способ знакомства
с приложением — локальный стек из репозитория.

## 1. Запустите локальный контур

Из корня репозитория выполните:

```bash
just doctor-local
just run_local --no-doppler
```

Откройте `http://localhost:3000/app`. Скрипт поднимает frontend, backend и
необходимые локальные сервисы. Это среда разработки и проверки, а не
защищённый Internet-facing production.

<Note>
  Для команд нужны Nix и работающий Docker runtime. В Cursor Cloud используйте
  поддерживаемые entrypoints `bash .cursor/infra.sh` и `bash .cursor/stack.sh`.
</Note>

## 2. Войдите в приложение

Локальная сборка поддерживает вход по одноразовому коду. Введите тестовый
email, затем откройте Mailpit по адресу `http://localhost:8025` и возьмите код
из письма. Предварительно создавать пользователя не нужно.

Google, GitHub и другие внешние способы входа требуют собственных credentials
оператора. Локальный вход не доказывает, что внешний OAuth уже настроен.

## 3. Выберите язык

Новый профиль запускается на русском. Переключатель языка находится в
настройках аккаунта; выбор сохраняется в браузере и обновляет язык документа.
Если перевода для строки нет, используется английский fallback.

## 4. Освойте основные клавиши

| Клавиша                       | Действие                                                                 |
| ----------------------------- | ------------------------------------------------------------------------ |
| <kbd>c</kbd>                  | Открыть меню создания блока                                              |
| <kbd>cmd</kbd> + <kbd>k</kbd> | Открыть меню команд                                                      |
| <kbd>/</kbd>                  | Открыть [поиск](/product/search)                                         |
| <kbd>j</kbd> / <kbd>k</kbd>   | Перейти к следующему или предыдущему элементу списка                     |
| <kbd>e</kbd>                  | Завершить действие для выбранного элемента, например архивировать письмо |

Полный перечень находится в разделе
[«Клавиатурные сокращения»](/keyboard-shortcuts).

## 5. Создайте блоки и свяжите их

Создайте документ, задачу или канал через меню <kbd>c</kbd>. Используйте
@mention, чтобы связать материалы. Упоминание в канале также может выдать
доступ его участникам, поэтому перед отправкой проверьте состав канала.

Чтобы открыть два блока рядом, создайте разделённую область с помощью

<kbd>cmd</kbd> + <kbd>\\</kbd>. Подробнее — в разделе
[«Блоки»](/concepts/blocks#splits).

## 6. Создайте команду

Откройте раздел **Команда** в нижней части боковой панели, создайте команду и
пригласите участников. В Conation нет платных мест: команды доступны без
продуктовой подписки. Расходы на инфраструктуру несёт владелец развёртывания.

Доступ к материалам определяется ролями, каналами и настройками публикации.
Подробности — в разделах [«Команды»](/account/teams) и
[«Разрешения»](/permissions).

## 7. Подключите внешние возможности

- **Почта.** Рабочая синхронизация inbox сейчас требует Gmail или Google
  Workspace и OAuth credentials оператора. Локальный Mailpit принимает
  транзакционные письма, но не заменяет пользовательский inbox.
- **AI.** Агентам нужен доступ к настроенному модельному провайдеру. Без ключа
  соответствующий сервис может быть недоступен или вернуть явную ошибку.
- **GitHub.** Интеграция требует отдельной настройки OAuth/App. См.
  [«GitHub»](/integrations/github).
- **MCP.** MCP-клиент подключается к endpoint вашего оператора. См.
  [«Настройка MCP»](/AI/mcp/overview).
