В Conation почти всё рабочее содержимое представлено как **блок**. Блок можно открыть, упомянуть, встроить в документ, найти через общий поиск и связать с другими объектами.

Текущие встроенные типы блоков: `md` (документы), `email`, `channel`, `chat` (агенты), `automation`, `project` (задачи), `contact` (CRM), `company` (CRM), `call`, `canvas`, `code`, `image`, `video`, `pdf` и `unknown` как резервный тип для неизвестных объектов.

## Панели

В настольной версии Conation работает как рабочая поверхность с несколькими панелями внутри одной вкладки браузера. На мобильных устройствах этот режим не используется.

Обычно <kbd>shift</kbd> + click по @упоминанию или элементу списка открывает объект в новой панели.

У каждой панели есть собственная история навигации. Используйте <kbd>opt</kbd> + <kbd>[</kbd> и <kbd>opt</kbd> + <kbd>]</kbd>, чтобы перейти назад или вперед, либо нажимайте кнопки-стрелки в верхней панели.

Создать новую панель: <kbd>cmd</kbd> + <kbd>{"\\"}</kbd>.

Перевести фокус влево или вправо: <kbd>shift</kbd> + <kbd>h</kbd> / <kbd>shift</kbd> + <kbd>l</kbd>.

Развернуть текущую панель: <kbd>shift</kbd> + <kbd>escape</kbd>.

Закрыть панель: <kbd>cmd</kbd> + <kbd>escape</kbd>.

Количество одновременно открытых панелей зависит от размера монитора и масштаба интерфейса. Если места недостаточно, Conation не откроет новую панель, пока вы не закроете одну из текущих.

## Предпросмотр

У большинства типов блоков есть предпросмотр при наведении: можно быстро понять контекст, не открывая объект полностью. Если упомянуть блок в области Markdown — например в задаче, документе или канале — другие пользователи увидят предпросмотр при наведении.

Предпросмотр особенно полезен для задач, документов, email-тредов и файлов: он сокращает переключения между экранами и помогает читать обсуждение без потери контекста.

## Встроенные блоки

Большинство блоков можно встроить в markdown-документ в режиме только для чтения. Встроенный блок сохраняет контекст прямо внутри документа, но инструменты редактирования и разметки при этом отключены.

Права доступа не выдаются автоматически для встроенных блоков и упоминаний в документах. Это отличается от упоминаний в каналах, где участники канала получают доступ автоматически. Если вы встраиваете файл или документ, отдельно проверьте настройки доступа.

Чтобы встроить блок, сначала добавьте @упоминание через `@` или перетащите объект в документ, затем наведите курсор и выберите **Встроить блок**.

## Связи между блоками

- **Ссылки, доступ и права:** у каждого блока есть панель References с обратными ссылками на места, где блок упомянут или встроен. Диалог доступа использует общую модель прав: owner, editor, commenter, viewer и public links для документов.
- **Совместное редактирование:** совместные блоки, например документы и PDF-разметка, синхронизируются через **Loro CRDTs** поверх **Cloudflare Durable Objects**. Rust `sync-service` создает одну Durable Object room на документ, а клиенты подключаются по WebSocket к `/document/:id`.
- **Search и Inbox:** общий [поиск](/product/search) индексирует все типы блоков и поддерживает фильтры по типу и упомянутым людям. [Единые входящие](/product/inbox) собирают открытые уведомления из разных блоков в один список по времени.
