Свойства добавляют структурированные данные к блокам: письмам, задачам, документам, CRM-записям и другим объектам. Система свойств общая для разных блоков, но набор полей может отличаться по типу объекта.

<Note>
  Старые скриншоты прежнего интерфейса убраны из активной страницы. Новые
  иллюстрации свойств нужно подготовить в Conation на синтетических данных.
</Note>

## Типы данных

Блоки, которые поддерживают свойства, могут использовать общие типы данных:

- **STRING** — текст: телефон, должность, отдел, заметки.
- **NUMBER** — число: выручка, количество сотрудников, ARR.
- **BOOLEAN** — переключатель true/false.
- **DATE** — дата: последний контакт, срок договора, дедлайн.
- **SELECT_STRING** — один или несколько строковых вариантов с цветами и иконками.
- **SELECT_NUMBER** — один или несколько числовых вариантов.
- **ENTITY** — ссылка на другой объект: User, Company, Contact, Document, Project, Channel, Chat, Task или Thread.
- **LINK** — URL: сайт, профиль, внешний документ.

## Системные и пользовательские свойства

Свойство может быть **system** или **custom**.

System-свойства встроены в продукт и обычно не удаляются: например Status, Priority и Assignees у задач.

Custom-свойства создает команда. Их удобно использовать для полей, которые нужны вашему процессу: регион, риск, договор, владелец клиента, дата следующего контакта.

Свойство также может быть metadata. Такие поля доступны системе, но не обязательно показываются в основных списках.

## Закрепленные свойства

Свойство можно закрепить, чтобы оно отображалось в карточке справа или в unified list. Если поле нужно редко, оставьте его скрытым. Если поле влияет на ежедневную работу, закрепите его.

У разных блоков могут быть разные defaults. Например, задачи обычно показывают Status, Priority и Assignees.

## Встроенные поля по блокам

- **Задачи:** Status, Priority, Assignees, Due Date, Parent Task, Subtasks, Depends On, Effort, Story Points, Relevant Documents. Подробнее: [задачи](/product/tasks).
- **Документы:** Owner, Folder, Created, Updated и дополнительные привязки через свойства. Подробнее: [документы](/product/docs).
- **CRM companies:** Stage, Owner, Revenue и Last Interaction, если источник данных настроен и разрешен.
- **CRM contacts:** Email, Name, Company, interaction timestamps, domains и другие поля, зависящие от конфигурации CRM.

## Доступ агентов

Агенты читают и обновляют свойства через MCP-инструменты для объектов: `GetEntityProperties`, `SetEntityProperty`, `CreateCustomProperty` и `ListEntities`. Агент может работать только с теми объектами и полями, к которым у пользователя есть доступ. Справочник: [инструменты MCP](/AI/mcp/tools/index).
