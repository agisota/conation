# Инструкции для документационного проекта

## О проекте

- Это сайт документации [Conation](https://conation.dev), размещаемый на `docs.conation.dev` и собранный с помощью [Mintlify](https://mintlify.com).
- Страницы — MDX-файлы с YAML frontmatter.
- Конфигурация находится в `docs.json`.
- Для локального предпросмотра используйте `mint dev`.
- Для проверки ссылок используйте `mint broken-links`.
- Справочные страницы MCP-инструментов в `AI/mcp/tools/` генерируются `scripts/generate-mcp-tool-pages.ts` из Rust-схем в `crates/ai_tools`: исправляйте генератор или схемы, а не результат генерации.

## Термины

- **Блок** — базовая единица Conation: документ, письмо, канал, задача, звонок, холст и т. п. Используйте «блок», а не «модуль» или «приложение».
- Для ссылок, созданных через `@`, используйте термин **@упоминание**, а не «тег».
- Используйте **канал** (не «чат-комната»), **агент** (не «бот») и **рабочее пространство** для всей среды пользователя Conation.
- Для двух уровней памяти используйте **личная память** и **память команды**.
- **Signal** и **Noise** пишутся с заглавной буквы, когда речь идёт о представлениях входящих и почты.
- Названия сторонних продуктов пишутся в официальной форме: GitHub, Gmail, Notion, Slack.

## Стиль

- Пишите активным залогом и обращайтесь к читателю на «вы».
- Делайте предложения короткими: одна мысль — одно предложение.
- Заголовки оформляйте в естественном регистре русского языка.
- Элементы интерфейса выделяйте полужирным: нажмите **Настройки**.
- Имена файлов, команды, пути и фрагменты кода оформляйте как код.
- Для сочетаний клавиш используйте `<kbd>`, например <kbd>c</kbd> + <kbd>t</kbd>.
- Скриншоты лежат в `images/` и требуют описательного alt-текста, а не имени файла.

## Границы содержания

- Документируйте продукт Conation; самохостинг описывайте на уровне, подтверждённом актуальной self-host документацией.
- Не документируйте внутренние инструменты, детали инфраструктуры или неанонсированные функции.
- Не создавайте черновые страницы или страницы с пометкой WIP: добавляйте страницу только когда для неё есть завершённый материал.
