# Визуальный реестр продуктовых ассетов — batch 3

Дата ручной проверки: 2026-09-02. Это ровно следующие 75 ещё не рассмотренных production-векторов из канонического набора в 296 ассетов после Batch 1 и Batch 2. Три brand deployment-артефакта и 12 email-rendering fixtures не включались в эту выборку; они исключены из canonical coverage, а не потеряны. Машиночитаемый состав и точные байтовые метаданные закреплены в [ASSET_VISUAL_INVENTORY_BATCH3.tsv](./ASSET_VISUAL_INVENTORY_BATCH3.tsv).

Все 75 файлов были открыты как SVG и дополнительно отрендерены в трёх контакт-листах по 25 плиток. Это статические SVG: кадров GIF/APNG/WebP в партии нет, следовательно покадровое GIF-описание для каждого файла — «неприменимо». Размер, размерность, SHA-256 и отметка отсутствия анимации указаны в TSV для каждой строки без округления.

Общие условия:

- **U** — исходный upstream-вектор из репозитория; отдельная лицензия на рисунок в файле не обнаружена. В этой партии нет персональных данных и нет Macro wordmark.
- **T** — знак стороннего поставщика; использовать можно только при реальном выборе/интеграции поставщика и после проверки его brand guidelines.
- Все generic-иконки используют одноцветный SVG с currentColor. Сам по себе знак не является доступным названием действия: у интерактивного consumer должен быть русскоязычный текст, aria-label или tooltip. Статусы приоритета нельзя передавать только интенсивностью цвета.
- **keep** означает, что нейтральный знак может остаться в Conation. **review** не означает удалить: это инвентарный флаг для проверки реального consumer, динамической загрузки либо права на знак перед публичным релизом.
