Состав партии намеренно сохранён из частичной TSV и не пересекается с [Batch 1](./ASSET_VISUAL_INVENTORY_BATCH1.tsv) по пути. Три новые пользовательские копии в `apps/docs/brand/` исключены из счётчика и этой партии. Все строки ниже сверены с текущим байтовым файлом; GIF в этой партии отсутствуют, поэтому покадрового GIF-аудита нет.

Колонки `metadata` в [ASSET_VISUAL_INVENTORY_BATCH2.tsv](./ASSET_VISUAL_INVENTORY_BATCH2.tsv) являются каноническими: формат, размер, пиксели, число кадров, длительность и SHA-256 приведены без округления. `S` — upstream screenshot; `U` — upstream/legacy; `C` — Conation/user-provided migration master; `T` — сторонний товарный знак. Статус `replace` означает, что production-файл нельзя оставлять без замены/редакции; `keep` — сохранить; `review` — оставить только после отдельного решения о дубликате, лицензии или потребителе.
