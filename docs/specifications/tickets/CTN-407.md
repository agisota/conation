> **Medium Risk**
> Touches local-only auth redirect allowlists, OAuth/CORS admission, and S3 presigned URL rewriting; validation is strict but mistakes could weaken redirect or origin checks in local mode.
>
> **Overview**
> Adds **`--public-origin https://host[:port]`** so a fully local stack can be used from a **browser-trusted HTTPS URL** (e.g. Tailscale Serve) without changing deployed config. Default localhost behavior is unchanged when the flag is omitted.
>
> **Orchestration (`xtask_local`)** validates and persists the origin, injects browser-facing env (`OVERRIDE_APP_SERVICE_URL`, `LOCAL_AWS_PUBLIC_URL`, `LOCAL_PUBLIC_ORIGIN`, FusionAuth redirect URLs, etc.), wires Vite to **`same-origin`** + loopback proxy target, extends Caddy with **`/s3`** (SigV4-preserving LocalStack proxy) and **`/oauth2/*`**, and updates FusionAuth kickstart for new DBs. **`run_dev`** and changing origin on **`stack update`** are explicitly blocked or documented as in-place only.
>
> **Frontend** uses a new Vite helper to bind **`127.0.0.1`**, allow the public host, proxy only inventoried backend prefixes (with WS), and derive HMR from the browser; local logout and passwordless redirects follow **HTTPS** when the page is not plain HTTP.
>
> **Auth & sync** accept the configured origin for SSO `original_url` and post-login redirects in local only; the sync worker admits that origin in CORS when `ENVIRONMENT=local` and `LOCAL_PUBLIC_ORIGIN` is set (also passed into the Docker sync image via `.dev.vars`).
>
> **S3 (`macro_aws_config`)** rewrites LocalStack URLs to **`{origin}/s3/...`** for the browser and maps them back for in-container fetches without breaking encoded paths or signatures.
>
> Docs cover Tailscale Serve setup, non-destructive reconfiguration, and agent login over the public URL.
