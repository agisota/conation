## Mission

Integrate the landed RUS-1454 service-scoped Doppler delivery, RUS-1455 exclusive configuration-source selection and RUS-1456 explicit backend selector; do not implement competing versions. If `APP_SECRETS_JSON` is present it supplies **all** public and secret application settings, with no same-name or disjoint public-key flat overlay, even if a producer explicitly asks to mix; flat env is allowed only as the complete alternative when JSON is absent. Independently require an explicit `SECRETS_BACKEND=env|aws`: production `env` uses Doppler values literally without Secrets Manager requests, while `aws` looks up a distinct name reference and fails without fallback. Deliver a non-secret, service-scoped production key/config map and safe startup validation, never `ENVIRONMENT=local` for production. T04/T05 are acceptance scenarios, not evidence executed by the cited static snapshot.
