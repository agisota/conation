Resolve the pull request review feedback and address any failed CI checks.

PR: https://github.com/macro-inc/macro/pull/6359
Branch: wolf/ios-appetize-preview → main

Add the `ios-preview` label to a PR and CI builds an arm64 iOS Simulator `.app`, publishes it to an Appetize app owned by that PR, and posts a comment with one link per device size:

> **iOS preview** — `branch` @ `abc1234`
>
> [iPhone 15 Pro](#) · [iPhone 16 Pro Max](#) · [iPad Pro 12.9"](#)

`device` is a query parameter over one uploaded build, so extra sizes cost nothing — no rebuild, no second upload. `autoplay=false` means the simulator boots (and bills) only when someone clicks, so an unopened preview is free. Pushing to a labelled PR rebuilds and edits the same comment in place; removing the label stops it; closing the PR deletes the Appetize app.

**Verified end to end**: the app streams and renders on Appetize (welcome screen, not a black screen), from a browser with no Appetize account.
