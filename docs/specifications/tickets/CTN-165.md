<!-- fusion-original-description:start -->
Resolve the pull request review feedback and address any failed CI checks.

PR: https://github.com/macro-inc/macro/pull/6720
Branch: gab-reminders-04-alerts → gab-reminders-01-navigation

A delivered reminder currently has no foreground alert, so it can be missed while Macro is open even if its notification is stored. This adds a persistent in-app reminder card, independent of browser notification permission, with direct reminder navigation and a grouped view for bursts. Returning to the tab catches up from the loaded notification feed; live deliveries also alert when their entity is outside the loaded Soup page.

Acknowledgement is scoped to a delivered occurrence and browser account, survives reloads, and converges across tabs. Closing or opening the card does not complete or snooze a reminder. A reminder arriving during the close animation remains pending. Dedicated desktop/mobile toast regions keep save/copy feedback from replacing reminders.

The GraphQL adapter now preserves `scheduledFor` for transport-consistent occurrence deduplication. Logout evicts notification queries and clears the live reminder buffer to prevent a previous account's reminders from appearing after native account switching.

Validation: full web suite (773 files, 7,019 passing tests, one existing TODO), followed by 175 combined reminder/navigation tests across twenty files after review fixes and the updated navigation parent; full frontend TypeScript; generated GraphQL artifacts; `just check`; CI-equivalent Biome and import-cycle checks (existing warning-only cycles). The main-base-only web workflow does not run on this stacked PR, so these checks were run locally. Browser checks use the production controller/presenter/Toast components with fixture data: permission denied, persistence, burst grouping, open actions, reload, focus catch-up, close-animation arrival, Escape, cross-tab acknowledgement, and 390px touch layout. No hosted data was changed. Full app integration against hosted dev was limited by an unavailable authenticated browser session.

Stack: based on #6719 (reminder navigation). An isolated integration merge with composer #6725 passed 378 tests across 32 files and the full frontend TypeScript check. Browser-closed Web Push, per-occurrence Done/Snooze, and cross-device acknowledgement are separate follow-ups.
