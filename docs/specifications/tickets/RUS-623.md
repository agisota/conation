> [!NOTE]
> **High Risk**
> Touches OAuth/login, account linking, session redirects, and deep-link routing across platforms, plus new native Android auth and TLS initialization—areas where regressions affect access and session safety.
>
> **Overview**
> Introduces **Android as a buildable Tauri target** with `just android-dev` / `android-build`, Firebase project validation, release signing hooks, and new Android development docs.
>
> Adds a **`tauri-plugin-android-auth`** (Auth Tab + per-attempt `macro://android-auth/<uuid>` callbacks) and routes **SSO, GitHub, and Gmail linking** through shared `createNativeAuthSession`, replacing iOS-only `invoke('plugin:auth|authenticate')` paths. **Native post-login redirects**, Android deep-link routing through a session gate, and **checkout/query preservation** on hash-router launches are updated so links and Stripe return params survive cold start and late navigation.
>
> **Tauri shell changes** split iOS vs Android capabilities/plugins, initialize **rustls platform TLS** on Android, scope app links to `com.macro.app.prod` / `macro://app`, and **defer Android remote push registration** until Firebase push work lands. Includes broad unit tests; also adds `VITE_POSTHOG_API_KEY` to production env.
