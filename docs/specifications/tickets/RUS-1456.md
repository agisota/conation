## Mission

Add required, typed, process-stable `SECRETS_BACKEND=env|aws` selection at the existing `remote_env_var`/`secretsmanager_client` boundary, independent of `macro_env::Environment`. Env mode uses Doppler-injected fields as literals with zero AWS secret lookups; aws mode treats fields as names resolved through each service's Secrets Manager, with no fallback on failure. Integrate derived and direct consumers, restore `run_dev`'s develop identity, preserve environment-driven guards and RUS-1455's configuration-source and RUS-1454's delivery contracts. Do not introduce a hybrid resolver.
