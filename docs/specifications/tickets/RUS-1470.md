## Goal and original user request

## What This Delivers

A canvas with writing, shapes, connections, and images survives browser reload and a server restart on the operator's own installation. People can download and import it without losing its structure or chosen colors. When saving fails, the screen says so and keeps their work available to retry; editing while disconnected and restoring the same tab does not silently claim the work was saved.

## Mission

Preserve the existing block-canvas editor while making its create → upload → versioned load → edit → `simpleSave` → reload → export/download → Drive import path reliable on the operator-owned DSS/SFS and RUS-1451 domains. Implement a single-document acknowledgment and recovery contract: visible saving/saved/error or unsaved status in standalone and Drive, ordered server-confirmed saves, valid latest downloadable bytes, and a protected per-document same-tab draft during DSS outage (or genuinely effective loss prevention with explicit retry). Validate persisted text, shapes, actual edge endpoints, image bytes/reference and links through browser closure and nondestructive server restart. This is not the autonomous offline queue or collaboration/ACL work of RUS-1513 and RUS-1471.
