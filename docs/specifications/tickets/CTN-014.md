## Mission

Extend the `memory` crate and cognition settings UI for durable personal and team-scoped memory management. Today `memory` is one **personal** row per user, not a workspace row; `MemoryServiceImpl::get_or_generate_memory` launches background research when absent or stale. Introduce a **separate**, manually curated workspace block per team rather than pretending this already exists. Existing users remain opted in by default; personal opt-out stops automatic research for the user, team admin/owner opt-out stops it for all current members even if their personal preference is on. Neither switch deletes saved text or stops use of that text in assistant prompts; explain this in UI. Manual personal edits remain authoritative until the owner explicitly resumes automatic refresh. Team memory is manually managed, never synthesized by the personal research agent. A user without a team retains personal management. Task-relevant project memory search returned only empty templates, so there is no additional durable convention to apply.
