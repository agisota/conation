> [!NOTE]
> **Medium Risk**
> Touches core channel navigation, split state capture, and multiple entry points (block, Chat, entity detail); incorrect target consumption or memoization could cause missed jumps or unwanted re-navigation.
>
> **Overview**
> Introduces a **composable channel stack** (`ChannelSurface`, `ChannelMessages`, shared tab/icon/live-indicator hooks) so message navigation, thread resolution, and timeline persistence are owned outside the block adapter. The channel block now drives navigation via `ChannelTargetRequest` state instead of awaiting a messages handle and inline `resolveTargetMessage` logic.
>
> Adds **`ChannelDetail`** as the Markdown-style inline host (tabs, top bar, Ask Macro/Call) and wires it into **Chat** (`ChannelDetailView` replacing `PreviewPanel`) and **`EntityDetail`** for channel / message / thread targets. Navigation keys are stabilized so metadata or notification read reconciliation does not re-scroll an open conversation.
>
> **Behavior fix:** leaving the Messages tab and returning restores scroll, threads, and reply state (documented in `channels.md`). Split-block rename/picture menu behavior is unchanged; inline detail omits the title `...` menu per docs.
