## Goal and original user request

## What This Delivers

A person can manually ask the built-in agent to use a document they are allowed to read and prepare a separate draft for review. They can see which source it used, what it did and the resulting draft, then reconnect to the same conversation, including after a service restart. An inaccessible document or unavailable model produces a clear failure; the draft is not sent to anyone.

## Mission

Enable the existing `MACRO_NEW_BOT_ID` / `agent_inmem` route in RUS-1448's actual production self-host profile as a single manually started workflow: an authenticated owner specifies a document ID, the runtime uses owner-scoped Macro MCP `ReadContent` and `CreateDocument` to produce a distinct Markdown draft, records source/tool/result frames for the existing transcript, and resumes the same ACP session with authorized tools on browser and cold process reconnect.
