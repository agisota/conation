## Goal and original user request

## What This Delivers

Administrators can organize teammates into departments and positions, set reporting relationships and link existing agents without changing team membership. A former colleague loses access immediately, and private agents remain invisible to unauthorized viewers. Two competing edits cannot silently overwrite one another; a later organization canvas can rely on a documented server contract.
