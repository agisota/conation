## Goal and original user request

## What This Delivers

People can select an agent model their deployment can actually use, watch its response arrive, and see the results of available tools. A self-hosted operator can run the ordinary document-to-draft agent without optional external services. When a selected service fails, the reason is visible and the request is not quietly sent elsewhere.

## Mission

Make discovery and external tool policy capability-aware for the AG-01 self-hosted in-process agent. Harness Config currently requires a Pipedream triple and main builds its client and two EgressProvisioners; RigTurnEngine advertises CHAT_MODELS while ModelRouter::agent calls route_or_default on unknown IDs. Keep internal Macro MCP, owner-scoped grants and independently authenticated Cursor, Claude, Codex, macrod and external harnesses. An explicit unavailable model must fail without provider substitution; an unselected default may resolve to a deterministic eligible configured model in the same harness only, reporting its real identity. Deployment-scoped local provider wiring is in scope, not CTN-051's per-user arbitrary endpoints.
