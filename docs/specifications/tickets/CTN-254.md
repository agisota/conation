Resolve the pull request review feedback and address any failed CI checks.

PR: https://github.com/macro-inc/macro/pull/6629
Branch: wolf/agent-live-previews → main

Agents can share a running local development server and keep iterating with HTTP/WebSocket HMR. The internal `SharePreview({port})` MCP tool returns a stock OpenSSH script; Cursor and macrod sessions show an “Agent is sharing a preview” banner with View preview and Stop sharing controls.

- Adds a separate russh gateway with a one-use token in the SSH username, pinned server host key, and logical reverse forwards. No helper binary, client key setup, or per-preview public TCP listener.
- Gives each preview an isolated HTTPS origin. Standard session entity View access issues a short-lived POST ticket and host-only browser cookie; application paths and query strings stay intact. Access is rechecked during requests and streams, and stopping closes active traffic.
- Adds owner quotas, shared bandwidth/request limits, connection limits, expiry, and idle cleanup. Reuses existing session MCP credentials, including external macrod attachment, while keeping local host and Docker addresses reachable.
- Wires realtime banner updates, local Compose/Caddy/Nix support, a single-replica Pulumi service with HTTPS/SSH ingress, deployment inventory, and generated dependency metadata.

Validation: 501 unit tests across agent_preview, preview_gateway, agent_harness, agent_egress, macro_entrypoint, macro_service_urls, and xtask_local; doc tests; changed-package Clippy; full web checks; preview infrastructure TypeScript; dependency/workflow generation checks. The SSH test calls the real MCP endpoint, executes its returned script, and verifies HTTP, WebSockets, and stop cancellation. Chromium reproduced the browser ticket/cookie/redirect/form flow; fresh Caddy storage passed a trusted wildcard TLS handshake. Clippy reports two existing warnings in unchanged code.

Before deployment, choose an isolated preview domain outside macro.com and Route 53 zone, initialize the preview-gateway Doppler project/config, and provision its persistent SSH host key and existing service secret references. The service is not deployed by this PR. See `services/preview_gateway/README.md` for rollout, local CA trust, limits, and provider constraints. Existing Cursor agents need a new session to receive the MCP server; hosted Codex Cloud currently rejects MCP, and Claude Cloud's outbound SSH networking remains unverified. Codex/Claude through macrod use the external ACP path.
