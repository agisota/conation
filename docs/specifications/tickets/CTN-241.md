Failed agent turns were easy to miss: sidebar rows looked like any other conversation, and the transcript showed a truncated red rule.

This change:

- Marks errored sessions in the Agents (and Home) list with a warning icon and red **Error** subtext. An open session publishes its newest failed turn to that row; soup `failed` / `error` status also shows it.

- The session side-panel Status pill reads **Error** while the newest turn failed.
