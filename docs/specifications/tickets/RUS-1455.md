## Mission

Establish one production source per enabled service/worker: ECS uses complete versioned `APP_SECRETS_JSON` synced from its own Doppler, and RUS-1454 self-host production may use complete atomically staged per-key env **only when JSON is absent**. Present JSON alone supplies public and secret application keys; missing/blank/invalid required values, a duplicate flat source, and an independently stale revision fail closed. Coordinate fresh fetch and controlled process replacement after rotation, leaving local development distinct. Reconcile an incompatible landed producer rather than exempting it; leave AWS/env resolution of an individual remote secret to RUS-1456.
