> [!NOTE]
> **Medium Risk**
> Touches multi-tab cache coordinator protocol (v4), backfill checkpoint semantics, and Quick Access data gating—incorrect `openOutcome` mapping could skip needed resets or wipe durable progress.
>
> **Overview**
> **Bumps the cache coordinator to protocol v4** so `engine-replaced` broadcasts carry an **`openOutcome`** (e.g. `opened-existing` vs reset paths). The worker cache host maps that into **`onCacheGenerationChanged({ storage: 'preserved' | 'reset' })`**, separating in-memory engine invalidation from whether durable cache data survived.
>
> **Soup backfill** now **only clears local checkpoints when `storage === 'reset'`**; a normal owner handoff that reopens existing storage keeps cursors and completed watermarks. Tests cover obsolete in-flight page completions, lane watermarks, and leadership transfer without redundant refetch.
>
> **Quick Access** reads history, channels, and recently-viewed **only after query `isSuccess`**, so pending or failed lookups yield empty lists instead of treating stale `data` as authoritative. New integration tests assert the **app shell stays mounted** through pending resolve/reject for those sources.
>
> Coordinator/router/adapter, browser harnesses, and navigation docs are updated to match the new semantics.
