## Goal and original user request

## What This Delivers

Two permitted people can edit the same canvas, go offline, reconnect and reopen it to see the same result without losing either person's separate changes. If they change the same connection, the result is visible rather than silently replacing someone's work. Viewers cannot edit, and revoked people cannot see or change the canvas even with an old session; failed saves stay visibly pending until truly confirmed.
