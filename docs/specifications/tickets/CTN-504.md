> UI-only collapsed-thread preview logic; expanded message rendering is unchanged.
>
> **Overview**
> Collapsed thread previews no longer show raw markdown in signatures and links for Macro-authored messages.
>
> **`CollapsedMessage`** now delegates one-line snippet text to a shared **`messageSnippet`** helper instead of inlining `body_text` / HTML parsing. If HTML is missing, it strips common markdown markup from **`body_macro`**. Received mail without **`body_macro`** still uses plaintext first (including literal asterisks), with HTML only as a fallback when text is empty or whitespace.
>
> Vitest coverage documents signature stripping, replyless preference, block-element spacing, and received-mail behavior.
