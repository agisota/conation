## Mission

Add consented profile-specific cron suggestions to `scheduled_action` using delivered AG-05 private managed profile provenance, CAL-03 readiness and AG-07 approval/policy. Persist owner consent and revision, IANA schedule, hard per-run and per-local-day cost/token ceilings plus run allowance, and a unique durable occurrence with journal/usage and recovery state. Run the selected profile via managed `agent_session` open/status/close, not a synthetic legacy `AgentTaskRunner` profile; preserve old unprofiled `ActionKind::Agent`, cron/manual, Kafka event and any landed `RemoteAgent` behavior. An automation-designer only proposes a rule; call completion remains webhook-driven. “Once” is at most one automatic side-effectful start per occurrence, not guaranteed successful completion or physical exactly-once third-party delivery; uncertain post-start retry needs explicit owner action.
