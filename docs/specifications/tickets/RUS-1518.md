## Goal and original user request

## What This Delivers

Team members can see their administrator's default board after reloading, while keeping their own board as their personal choice. Only administrators can edit the shared board. When two administrators edit concurrently, the second receives a real conflict and can reload or save a personal copy rather than erase the first person's work.

## Mission

Implement GET/PUT `/team/dashboard` in the existing authentication service team router, backed by a team-owned layout and monotonic revision in MacroDB, never personal `/saved_views`. Reuse the delivered RUS-1517 layout contract, allow verified team members to read and admins/owners to write, and require a strong revision-derived ETag/If-Match for every write, including creation and clear. Integrate the team default behind personal precedence only after server-side atomic compare-and-swap is proven; this plan does not claim the dependencies or runtime verification have been completed.
