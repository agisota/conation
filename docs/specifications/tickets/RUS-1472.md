## Mission

Using the delivered RUS-1498 token-to-role/state table and available `implementation_brief.md` §4, create one light `ThemeV3` preset in `apps/web/src/features/theme/themes/rox-warm-light.ts`, based on `macro-light.ts`, and register it once in `DEFAULT_THEMES`. Assign distinct warm surface depths, page, panel, chrome, edge, content and accent, including navigation `#E2DBD5`, page `#ECE5DF`, panel `#F8EFE7`, primary ink `#2D232E` and accent `#89500F` where the contract maps those values; preserve success/warning/failure, selected/hover/active, focus and code-highlight readability. Verify live computed contrast ≥4.5:1 for ordinary and secondary informational text against actual composited backgrounds, with a distinguishable focus indicator and safe missing/invalid-theme behavior. Keep existing ThemeV3 and CSS semantics, defaults and persistence unchanged; RUS-1473 owns initial selection/first frame, RUS-1474 density, RUS-1499 independent contrast QA, RUS-1502 full-screen matrix, and RUS-1503 integration verification rather than creation of this preset.
