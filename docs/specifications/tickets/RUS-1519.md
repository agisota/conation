## Goal and original user request

## What This Delivers

People permitted to edit their organization's structure see departments, positions, colleagues and eligible agents on a shared canvas. Moving a person to a valid destination, or doing the same action with a keyboard, changes the real organization once and lets another participant see it. If another change wins first, the display shows the current structure and retains the attempted change for deliberate review; a drawing cannot grant permissions or become a competing personnel register.
