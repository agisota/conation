## Goal and original user request

## What This Delivers

Operators get a trustworthy release decision for a named installation: teammates can access what is deliberately shared, while another person's private mail, meetings, boards, agents and search results remain private. Removing access also blocks previously issued sessions and links where the acceptance contract requires it. A missing service, incomplete test or privacy leak blocks release rather than looking like success.
