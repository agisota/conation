After RUS-1472's palette and RUS-1500's delivered measurement map, implement a separate SolidJS `normal | compact` geometry preference using bounded HTML tokens inherited by both `#root` and `#modal`, connected to real common controls, both navigation implementations, split shells and affected lists.
