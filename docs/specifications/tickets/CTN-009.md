## Mission

Provide a minimal TypeScript manual CRM import/update example on the existing `@macro-inc/sdk` `Macro` facade, with real automated tests, documentation, and a maintainer-ready answer to issue #6103. Prefer a user key from **Settings → API Keys** for user-driven scripting; distinguish this from UI-minted bot tokens, session bearer tokens supplied by a legitimate token source, and MCP OAuth. Do not port unavailable Python code or create new authentication. The repo already implements SDK company/contact create and rename, CRM comments, and markdown document creation; MCP has `CreateDocument`, but the CRM toolset currently only exposes `ListCompanies`/`GetCompany` (separate property tools handle property writes). Recommend SDK writes and MCP for MCP-native read/search/discovery rather than reusing another program's token cache.
